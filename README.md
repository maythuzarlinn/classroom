### Prerequisites & Installation Guide.

- **[Download xampp](https://www.apachefriends.org/download.html)**
- **[Install xampp]**
- **[Clone classroom project under under C:\xampp\htdocs\ ](https://github.com/maythuzarlinn/classroom.git)**
- **[Check .env file for database name and create database in phpmyadmin.Note- if there is no .env file ,you can copy .env.example and rename as .env]**
- **[Open bash/cmd shell under classroom folder path]**
- **[Type "composer install" in bash terminal.]**
- **[After that make database table migration => type "php artisan migrate"]**
- **[After installing dependency and migration : run localhost =>Type "php artisan serve"]**

### Finally you can run project on localhost.
